# GuidForGamesOverlay

«Справка по игре» (как Game Help на PS5) для игр в Steam на ПК. Приложение показывает подсказки
по текущему прогрессу игрока прямо поверх игры и вызывается с клавиатуры или контроллера.

Это родственный проект [GuidForGames](https://github.com/NikAndrei/GuidForGames): там приложение-компаньон
для телефона, здесь те же подсказки показываются на основном экране.

## Документы

- [`docs/design.md`](docs/design.md): проектная записка (решения, архитектура, риски).
- [`docs/plan.md`](docs/plan.md): план MVP, связь с GuidForGames, открытые вопросы. Читать первым.

## Структура

```
service/                 сервис (Rust): наблюдатель за сейвами, адаптеры, движок правил, отладочная страница
adapters/<game>/         описание адаптера игры: откуда берётся состояние (код — service/src/adapter/)
hints/<game>/            правила «условие по состоянию → подсказка»
schemas/                 JSON Schema общих форматов (модель состояния, правила)
overlay/reshade-addon/   основной показ: аддон ReShade (C++) с окном на ImGui
window/                  запасной показ: прозрачное окно поверх игры
docs/                    записка и план
```

## Состояние

- Сервис на Rust готов: наблюдатель, адаптер DD2, правила, отладочная страница и протокол для оверлея.
  Как запустить — в [`service/README.md`](service/README.md).
- Следующий шаг — аддон ReShade.
