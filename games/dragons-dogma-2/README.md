# Dragon's Dogma 2 (Steam AppID 2054970)

Адаптер — `service/src/adapter/dd2.rs`. Два источника состояния:

1. **Мод-мост REFramework** (`mods/dd2/guidforgames.lua`, ставится командой `gfg-service install-mods`):
   пишет в `<игра>/reframework/data/` `guidforgames_live.json` раз в 2 с (позиция, отслеживаемый квест, область)
   и `guidforgames_state.json` при изменениях (журнал квестов). Если мод установлен, это основной источник.
2. **Сейв:** `<Steam>/userdata/<аккаунт>/2054970/remote/win64_save/`. Шифрование «Mandarin», ключ выводится
   из SteamID64, внутри данные RSZ. Расшифровывает `tools/dd2-save` (лежит рядом с `gfg-service.exe`),
   всегда на копии. Нужен, если мода нет; кроме того, только сейв знает квесты, ставшие недоступными.

Файлы:
- `game.json` — регионы и шкала прогресса (ступени по сюжету), `adapter`, `steamAppId`;
- `entries/*.json` — справочник: квесты, секреты, жетоны искателя, советы; у каждой записи лестница подсказок;
- `save-map.json` — номера квестов игры → записи и ступени прогресса (`confirmed: false` — предположение);
- `rules.json` — что показывать: отслеживаемый и начатые квесты, пропускаемое, новое на текущей ступени.

Данные перенесены из GuidForGames 03.11.2026 и дальше ведутся здесь.
Жетоны искателя (226 записей) правила пока не показывают: их слишком много для окна подсказок.
