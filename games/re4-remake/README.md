# Resident Evil 4 (ремейк, Steam AppID 2050650)

Адаптер — `service/src/adapter/re4.rs`. Источник состояния — **мод-мост REFramework** (`mods/re4/guidforgames.lua`,
ставится командой `gfg-service install-mods`): `<игра>/reframework/data/guidforgames_re4_live.json` раз в 2 с.
Сейв RE4 пока не разбирается.

- **Ступень прогресса** — самая дальняя глава прохождения (`mostChapter`, номер `chainsaw.ChapterID`),
  сопоставление — `save-map.json` → `chapters` (кампания Леона, главы 1–16).
- **Собранное** — флаги `file:<FileID>`, `item:<ItemID>`, `castellan:<глава куклы>`, `request:<QID>`
  и `chapter:<n>` для пройденных глав. Записи с такими `gameRefs` считаются сделанными и из окна пропадают.
- **Место** — `stage:<CurrentStageID>`.

Файлы:
- `game.json` — регионы, шкала прогресса (ch1–ch16, sw1–sw7 «Разных путей»), `adapter`, `steamAppId`;
- `entries/*.json` — 428 записей: прохождение, боссы, загадки, сокровища, кастеляны, маленькие ключи,
  поручения торговца, документы, «Разные пути», советы;
- `save-map.json` — номера глав игры → ступени;
- `rules.json` — что показывать: прохождение и загадки текущей главы, поручения, пропускаемое, собирательное.

Данные перенесены из GuidForGames 03.11.2026 и дальше ведутся здесь.

Не сделано:
- главы «Разных путей»: их номера `ChapterID` неизвестны, поэтому ступени sw1–sw7 мод пока не определяет;
- значки на игровой карте: мод рисует их по файлу `guidforgames_re4_marks.json`, который строил сервер GuidForGames
  (из сторонних карт). Без этого файла мод работает, просто без значков.
