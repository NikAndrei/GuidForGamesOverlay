# Сервис

Отдельный процесс. Падение при разборе сейва не должно ронять игру.

- наблюдатель за папкой сейвов (с debounce: игра пишет сейв в несколько приёмов);
- загрузка адаптеров и правил;
- движок правил → модель UI («актуально сейчас», карточки, уровни подсказок);
- named pipe или локальный сокет для оверлея и прозрачного окна;
- отладочная веб-страница состояния.

Язык ещё не выбран (см. `docs/plan.md`).
