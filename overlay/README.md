# Оверлей в рендере (основной путь)

`reshade-addon/` — аддон ReShade: окно на ImGui, подключается к сервису и показывает модель UI.
Ввод с контроллера идёт через SDL3, пока окно открыто, ввод в игру подавляется.

Только для игр без античита и сетевого режима (белый список игр, блок-лист античитов).
Этот путь общий для всех игр, в том числе для игр на RE Engine (DD2, RE4), где мод-мост REFramework только
поставляет состояние. Протокол связи с сервисом описан в `service/README.md`.
