# Оверлей в рендере (основной путь): аддон ReShade

Окно «Справка по игре» рисуется внутри игры через [ReShade](https://reshade.me) — одинаково для всех игр,
которые ReShade поддерживает (DirectX 9–12, Vulkan, OpenGL). Логики в аддоне нет: подсказки, прогресс и раскрытые
уровни хранит сервис `gfg-service`, аддон получает от него модель UI по TCP (`service/README.md`) и показывает её.

Код и сборка — `reshade-addon/` (README там же).

## Установка

1. Поставить **ReShade с поддержкой аддонов** («with full add-on support») в игру — DD2.exe / re4.exe.
2. Положить `guidforgames.addon64` рядом с exe игры (там же, где `dxgi.dll` / `d3d12.dll` ReShade).
3. Запустить `gfg-service.exe` — до или после игры, окно подключится само.
4. Если русский текст в окне не виден (квадратики), у ReShade шрифт без кириллицы: в меню ReShade
   (Home) → Settings → Global font указать `C:\Windows\Fonts\segoeui.ttf` или переключить язык ReShade на русский.
   Окно подскажет это само.

## Управление

| | Клавиатура | Контроллер |
|---|---|---|
| Открыть / закрыть | **Shift+F1** | удерживать **View (Share) + R3** ~0,5 с |
| Выбор в списке | ↑ ↓ | крестовина / левый стик ↑ ↓ (с автоповтором) |
| Вкладки | ← → | LB / RB (или крестовина ← →) |
| Открыть карточку, раскрыть следующий уровень | Enter / Space | A / ✕ |
| Скрыть раскрытое | Delete | Y / △ |
| Назад / закрыть | Esc / Backspace | B / ○ |

Мышь тоже работает (кнопки, список, вкладки). Пока окно открыто, клавиатура и мышь до игры не доходят
(`block_input_next_frame`). **Контроллер игра слышит** — ReShade его не перехватывает; справку лучше открывать на паузе.
Контроллер опрашивается через XInput (Xbox и всё, что Steam Input показывает как Xbox-контроллер).

Вкладки: «Всё», «Прохождение» (quest, boss), «Загадки» (puzzle), «Собирательство» (secret, chest, file…), «Советы» (tip).
`(!)` в списке — можно пропустить: после какого-то момента сюжета уже не сделать.

## Настройки

В `ReShade.ini`, раздел `[GuidForGames]` (ключи появляются при первом запуске):

| Ключ | По умолчанию | |
|---|---|---|
| `Host`, `Port` | `127.0.0.1`, `7871` | где сервис |
| `AllowedExe` | `DD2.exe,re4.exe` | белый список игр: в остальных аддон не включается |
| `Hotkey` | `112,0,1,0` | клавиша как в ReShade: код, Ctrl, Shift, Alt (112 — F1) |
| `GamepadCombo` | `1` | `0` — не открывать окно с контроллера |

## Защита

- Аддон включается только в играх из `AllowedExe`.
- Если в процессе или рядом с exe есть признаки античита (EasyAntiCheat, BattlEye, Vanguard, XIGNCODE, GameGuard…),
  аддон не включается, даже если игра в белом списке; проверка повторяется каждые 10 с (античит может загрузиться позже).
  Причина пишется в журнал ReShade (`ReShade.log`).
