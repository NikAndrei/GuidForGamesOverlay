# Правила подсказок

`hints/<game>/*.json` — правила по схеме [`schemas/hints.schema.json`](../schemas/hints.schema.json):
условие по модели состояния → подсказка.

Текст подсказок по возможности не пишем здесь заново: правило ссылается на запись GuidForGames (`entry`),
а лестница из трёх уровней берётся из её `hints`. Свой `title` и `hints` нужны, только если записи нет.

Номера квестов DD2 — как ключи `data/dragons-dogma-2/save-map.json` в GuidForGames (`10050` ↔ `qu010050`).
Сервис проверяет правила при запуске: несуществующие записи и ступени прогресса видны в логе и на отладочной странице.
