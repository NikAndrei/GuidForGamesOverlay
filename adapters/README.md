# Адаптеры игр

Один адаптер на игру (`adapters/<game>/`). Что он делает:
- определяет игру (по exe или Steam AppID);
- знает, где лежат сейвы (и выходные файлы мода-моста, если он есть);
- расшифровывает, распаковывает и разбирает их;
- отдаёт общую модель состояния ([`schemas/state.schema.json`](../schemas/state.schema.json)).

Сейвы только читаем, и только копию.
