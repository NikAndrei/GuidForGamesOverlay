# GuidForGamesOverlay — план

Проектная записка: [`design.md`](design.md). Здесь — что делаем по шагам и как это связано с GuidForGames.

## Что уже есть в GuidForGames (переиспользуем)

| Что | Где в GuidForGames | Как используем здесь |
|---|---|---|
| Подсказки с лестницей из трёх ступеней (`hints[]`), RU+EN названия, `availableFrom` (ступень прогресса) | `data/<game>/entries/*.json`, пакеты в `NikAndrei/GuidForGames-packs` | Готовая база подсказок. Здесь добавляются только правила «состояние → какие записи актуальны сейчас» |
| Шкала прогресса игры (`progress[]`) и сопоставление ID квестов из сейва | `data/<game>/game.json`, `data/dragons-dogma-2/save-map.json` | Общая модель состояния, поля `progress` и `quests` |
| Расшифровка и разбор сейва DD2 («Mandarin», ключ из SteamID64, RSZ) | `tools/dd2-save` (Rust, поверх ree-save-editor), `docs/save-reading.md` | Пилотный адаптер DD2. Утилиту можно вызывать как есть или взять как библиотеку, если сервис будет на Rust |
| Мод-мост REFramework для DD2 и RE4: позиция, отслеживаемый квест, журнал, сундуки, глава и т.д. | `mods/dd2/guidforgames.lua`, `mods/re4/guidforgames.lua` → `reframework/data/guidforgames_*.json` | Второй источник состояния: точнее и быстрее сейва (обновляется раз в 2 с). Адаптер читает эти JSON |

Важный вывод: **REFramework уже встроен в рендер игр на RE Engine** (DD2, RE4) и уже даёт ImGui-окно и Lua.
Для этих игр самый короткий путь к «оверлею в рендере» — окно подсказок внутри того же мода, без ReShade.
Для этого нужно решить вопрос 1 ниже. ReShade-аддон остаётся универсальным путём для остальных игр.

## MVP

1. **Формат и модель.** JSON Schema общей модели состояния (`schemas/state.schema.json`) и правил подсказок
   (`schemas/hints.schema.json`). Пример правил для DD2 (`hints/dd2/`), который ссылается на записи GuidForGames.
2. **Сервис.** Наблюдатель за папкой сейвов (с debounce), интерфейс адаптера, движок правил, модель UI
   («актуально сейчас»), локальный сокет/named pipe и отладочная веб-страница состояния.
3. **Пилотный адаптер DD2.** Источник 1: сейв `win64_save/*` через `dd2-save`. Источник 2: `guidforgames_live.json`
   и `guidforgames_state.json` из мода-моста, если они есть.
4. **Показ в рендере.** Аддон ReShade с ImGui-окном: подключается к сервису, показывает список «актуально сейчас»
   и карточку подсказки, уровни раскрываются по одному.
5. **Контроллер (SDL3).** Вызов окна удержанием View/Share + R3 (~0,5 с), комбинацию можно переназначить.
   Навигация: крестовина/стик, A/✕ — раскрыть, B/○ — назад, LB/RB — вкладки. Пока окно открыто, ввод в игру подавляется.
6. **Запасной путь.** Прозрачное окно (Tauri/Electron/ImGui) на той же модели UI.
7. **Позже.** Проверить, можно ли писать в «Заметки» Steam. Второй адаптер (RE4) для проверки универсальности.

## Открытые вопросы

1. **Оверлей для игр на RE Engine:** ReShade-аддон или окно внутри мода-моста REFramework?
   За мод: он уже стоит, уже рисует и уже знает состояние. Против: работает только для RE Engine, и шрифт оверлея
   REFramework не всегда показывает кириллицу (нужен свой шрифт).
2. **Язык сервиса.** Rust: рядом с `dd2-save` и ree-save-editor. C++: рядом с оверлеем.
   C# или Python: адаптеры писать проще.
3. **Формат правил:** YAML или JSON. В GuidForGames данные в JSON, поэтому по умолчанию тоже JSON.
4. **Steam Input:** проверить, видит ли SDL3 контроллер, когда Steam подменяет его виртуальным.
