# GuidForGamesOverlay — план

Проектная записка: [`design.md`](design.md). Здесь — что делаем по шагам и что уже решено.

## Откуда что взято

Данные игр, моды-мосты и чтение сейва DD2 перенесены из GuidForGames 03.11.2026 и дальше ведутся здесь:

| Что | Здесь | В GuidForGames было |
|---|---|---|
| Справочник DD2 (354 записи) и RE4 (428), шкалы прогресса | `games/<game-id>/game.json`, `entries/` | `data/<game-id>/` |
| Номера квестов DD2 → записи и ступени; главы RE4 → ступени | `games/<game-id>/save-map.json` | `data/dragons-dogma-2/save-map.json`, `server/re4.ts` |
| Расшифровка и разбор сейва DD2 | `tools/dd2-save` (в общем workspace) | `tools/dd2-save` |
| Моды-мосты REFramework (dd2 v37, re4 v22) | `mods/dd2`, `mods/re4` | `mods/` |

## Принятые решения (03.11.2026)

- **Сервис — на Rust** (`service/`, крейт `gfg-service`). Рядом с `dd2-save` и ree-save-editor.
- **Показ — аддон ReShade для всех игр**, в том числе для игр на RE Engine. Окно внутри мода REFramework
  не делаем: путь через ReShade одинаков для всех игр, поэтому новые игры подключать проще. Мод-мост остаётся
  источником состояния, а не способом показа. ReShade и REFramework ставятся в одну игру вместе:
  совместимость цепочки хуков нужно проверить на DD2.
- **Связь с оверлеем — TCP на localhost, JSON по строкам** (протокол в `service/README.md`). Работает одинаково
  из аддона на C++ (Winsock) и из прозрачного окна. Named pipe не понадобился.
- **Правила — JSON**, как данные игр.
- **Самостоятельное приложение** (03.11.2026): от GuidForGames не зависим. Игры, сейвы и папки модов находятся
  в Steam сами (реестр, libraryfolders.vdf, appmanifest), `config.toml` необязателен.
  Моды ставит `gfg-service install-mods`. Готовый архив для Windows собирает GitHub Actions.

## MVP

1. ✅ **Формат и модель.** JSON Schema общей модели состояния (`schemas/state.schema.json`) и правил подсказок
   (`schemas/hints.schema.json`). Правила выбирают записи справочника наборами (`select`).
2. ✅ **Сервис.** Наблюдатель за папками (с debounce), интерфейс адаптера, движок правил, модель UI
   («актуально сейчас»), TCP-протокол для оверлея и отладочная веб-страница состояния.
3. ✅ **Пилотный адаптер DD2.** Источник 1: сейв `win64_save/*` через `dd2-save`. Источник 2: `guidforgames_live.json`
   и `guidforgames_state.json` из мода-моста, если они есть. Журнал квестов берётся из более свежего источника.
   Проверено на тестовых файлах мода и настоящих записях DD2. **Нужно проверить на ПК** с игрой: мод и сейв.
3a. ✅ **Адаптер RE4** по моду-мосту: самая дальняя глава → ступень, собранное (документы, предметы, кастеляны,
   поручения, пройденные главы) → флаги, сделанное из окна пропадает. **Нужно проверить на ПК** с игрой.
4. **Показ в рендере (следующий шаг).** Аддон ReShade (C++, `overlay/reshade-addon/`) с ImGui-окном: подключается к сервису, показывает список «актуально сейчас»
   и карточку подсказки, уровни раскрываются по одному.
5. ✅ **Контроллер — XInput** (вместо SDL3 для начала: без лишних DLL в процессе игры, Steam Input показывает
   контроллеры как Xbox). Вызов — удержание View/Share + R3 ~0,5 с; навигация: крестовина/стик, A/✕ — раскрыть,
   B/○ — назад, Y/△ — скрыть, LB/RB — вкладки. Клавиатура и мышь в игру не идут, пока окно открыто;
   **контроллер игра слышит** (ReShade его не перехватывает) — открывать справку на паузе.
   SDL3 — если понадобится DualSense без Steam Input.
6. ✅ **Запасной путь.** Прозрачное окно `gfg-window.exe` (`overlay/window/`): своё ImGui + DirectX 11, то же окно
   справки (`overlay/core/ui.cpp`). Спрятано, пока справка закрыта; по Shift+F1 / View+R3 разворачивается на мониторе
   игры и забирает фокус, Esc/B/клик мимо — возвращает фокус игре. Игра — по exe активного окна. Значок в трее.
   Только окно / окно без рамки. Собирается (mingw, MSVC в CI). Запущено под Wine (виртуальный экран, DirectX 11
   через wined3d): подключение к сервису, окно с кириллицей, клавиатура (вкладки, выбор, раскрытие уровня — сервис
   его записал), Esc прячет окно, «нет связи с сервисом». **Проверить на Windows:** вызов по Shift+F1 (под Wine
   глобальная клавиша не сработала), View+R3, возврат фокуса игре, прозрачность поверх игры.
7. **Позже.** Проверить, можно ли писать в «Заметки» Steam. Третья игра — по тому же пути: папка `games/<id>/`,
   адаптер, мод или чтение сейва.

## Открытые вопросы

1. **Проверить в игре:** аддон в DD2 и RE4; ReShade и REFramework вместе (оба встраиваются в DX12);
   прозрачное окно поверх DD2/RE4 в окне без рамки (фокус, затемнение, возврат в игру).
2. **Steam Input:** видит ли XInput контроллер, когда Steam подменяет его виртуальным.
3. **Кириллица в окне:** свой шрифт аддону не добавить (у ReShade нет такого API). Окно видит шрифт ReShade:
   русский язык ReShade (Calibri) или Global font с кириллицей; если нет — окно подсказывает, что поменять.
4. **Контроллер в игре:** пока окно открыто, игра тоже получает нажатия. Перехватить XInput можно только своим
   хуком — решить, нужно ли.
5. **Сколько показывать:** в RE4 на главу приходится до ~80 подсказок, пока мод не сообщил собранное. Вкладки
   по видам есть; возможно, нужен фильтр «рядом» по позиции игрока.
6. **«Разные пути» RE4:** номера глав `ChapterID` неизвестны — узнать по моду и дописать в `save-map.json`.
7. **Жетоны искателя DD2** (226): правила их не показывают; можно показывать ближайшие по позиции.
