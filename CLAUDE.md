# GuidForGamesOverlay

Game Help для ПК: контекстные подсказки поверх игры по текущему прогрессу, управление с клавиатуры и контроллера.
Сначала прочитать `docs/plan.md`, затем `docs/design.md`.

## Ключевые решения
- Самостоятельное приложение: данные игр (`games/<game-id>/`), моды-мосты (`mods/`) и чтение сейвов (`tools/dd2-save`)
  лежат здесь. От GuidForGames не зависим: данные и моды перенесены оттуда 03.11.2026 и дальше ведутся здесь.
- Универсальная система: ядро и UI пишутся один раз, под каждую игру добавляются адаптер (`service/src/adapter/`)
  и папка `games/<game-id>/` (game.json, entries/, save-map.json, rules.json, README.md).
- Контекст берётся из модов-мостов REFramework (игры на RE Engine) и файлов сохранений.
  Достижения Steam не используются. Игры, сейвы и папки модов находятся в Steam автоматически.
- Логика (сейвы, правила) живёт в отдельном процессе-сервисе. Оверлей только рисует.
- Сервис — на Rust (`service/`, `cargo test` перед коммитом). Связь с оверлеем — TCP на localhost, JSON по строкам
  (протокол описан в `service/README.md`, меняется только вместе с версией протокола).
- Показ — аддон ReShade (C++) для всех игр, в том числе для игр на RE Engine. Запасной путь — прозрачное окно поверх игры.
  Мод-мост REFramework — только источник состояния.
- Управление с контроллера обязательно: пока XInput (аддон, `overlay/reshade-addon/src/input.cpp`), SDL3 — если понадобится.
- Аддон (`overlay/reshade-addon/`): ядро без Windows тестируется на Linux (`ctest`), окно — предпросмотром
  `gfg_ui_preview` на настоящем ImGui; функции ImGui — только те, что есть в таблице ReShade (`reshade_overlay.hpp`).
- Формат записей справочника — как в GuidForGames (лестница подсказок: намёк → подробнее → полный спойлер,
  `availableFrom`/`missableAfter` по ступеням прогресса, `gameRefs` для автоотметки). Имена файлов модов прежние,
  чтобы оба приложения могли работать от одного мода.
- Правила (`rules.json`) выбирают записи наборами (`select`): по ступени, по квестам игры, пропускаемые.
  Сделанное (`gameRefs` во флагах, выполненные квесты) и упущенное отбрасывается автоматически.

## Правила
- Сохранения только читаем, и только копию. Файлы игры не меняем.
- Внедрение в рендер допускается только для игр без античита и без сетевого режима.
  Белый список игр и блок-лист античитов обязательны.
- Сейвы, ключи и SteamID — только локально (`.env`, `saves/`), не коммитить.
- Пользователь общается на русском, интерфейс и подсказки тоже на русском.
- Факты из гайдов пересказываются своими словами, с RU+EN названиями и ссылкой на источник. Дословно не копировать.
