# GuidForGamesOverlay

Game Help для ПК: контекстные подсказки поверх игры по текущему прогрессу, управление с клавиатуры и контроллера.
Сначала прочитать `docs/plan.md`, затем `docs/design.md`.

## Ключевые решения
- Универсальная система: ядро и UI пишутся один раз, под каждую игру добавляются адаптер (`service/src/adapter/`, описание — `adapters/<game>/`)
  и правила подсказок (`hints/<game>/`).
- Контекст берётся из файлов сохранений, а для игр на RE Engine ещё и из мода-моста REFramework из GuidForGames.
  Достижения Steam не используются.
- Логика (сейвы, правила) живёт в отдельном процессе-сервисе. Оверлей только рисует.
- Сервис — на Rust (`service/`, `cargo test` перед коммитом). Связь с оверлеем — TCP на localhost, JSON по строкам
  (протокол описан в `service/README.md`, меняется только вместе с версией протокола).
- Показ — аддон ReShade (C++) для всех игр, в том числе для игр на RE Engine. Запасной путь — прозрачное окно поверх игры.
  Мод-мост REFramework — только источник состояния.
- Управление с контроллера обязательно (SDL3 SDL_Gamepad).
- Контент подсказок общий с GuidForGames: формат записей и пакеты `NikAndrei/GuidForGames-packs`.
  Подсказки идут лестницей из трёх уровней: намёк → подробнее → полный спойлер.

## Правила
- Сохранения только читаем, и только копию. Файлы игры не меняем.
- Внедрение в рендер допускается только для игр без античита и без сетевого режима.
  Белый список игр и блок-лист античитов обязательны.
- Сейвы, ключи и SteamID — только локально (`.env`, `saves/`), не коммитить.
- Пользователь общается на русском, интерфейс и подсказки тоже на русском.
- Факты из гайдов пересказываются своими словами, с RU+EN названиями и ссылкой на источник. Дословно не копировать.
